# HIVOLT — Experiment Backlog

## Precondition

**No experiment on this list can be run yet.** At ~801 sessions / 14 days
(693 of them direct/bot) there is no statistical power for any test. Running an
A/B test at this volume produces noise that looks like a result — the most
expensive kind of mistake.

Traffic first. Then this backlog.

## Rules

- Never declare a winner without significance. Underpowered tests are not data.
- Every test needs a guardrail metric — AOV tests that quietly kill CVR are
  losses disguised as wins.
- HIVOLT's own data outranks any external benchmark (§71).
