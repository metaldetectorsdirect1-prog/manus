cheap gold washes, badges, golf-ball patterns, blue SaaS chrome.

## Typography

Host Grotesk 500 headings, 40px base, global uppercase — cinematic hero
scale via clamp(36–62px); Inter 400 body 16px; nav 14px uppercase; square
buttons, 800-weight uppercase labels (Impulse-native). Two families only —
no added weights (CWV protected).
