# HIVOLT — Merchandising Calendar

Planning opportunities, **not** automatic discount mandates (§66). A polo brand
that discounts constantly trains customers to wait.

## Geography matters

Do not run one global campaign. US patriotic moments do not travel; European
holiday rhythms differ from North American ones.

## Drop architecture

Polos suit a drop cadence because a customer can own many (§63):

- **Core** — permanent solid colourway range, always in stock
- **Seasonal** — colour drops aligned to the windows above
- **Limited** — small-run colourways creating collection behaviour
- **Performance / Golf** — only if product data supports the claim (§5)

Each drop needs: landing page, collection, campaign parameters, launch email,
inventory state handling, and a product-specific ad landing page (§20/§21).

## Discount discipline

Distinguish and keep separate: new-customer offer, bundle value, seasonal
promotion, limited drop, clearance, VIP. Blurring them destroys perceived value.
